# PAnoply 1.1.0

* `panoply_query()`: new arguments `mapping` (seven pathway mapping methods, `sgses_max` by default) and `db`
  (one pathway database). Default: the latest KEGG (human, disease pathways hsa05... excluded), downloaded from the
  KEGG REST API at run time and named as in the paper; also `"KEGG_ALL"`, a collection of `pathways`, or an MSigDB C2
  canonical-pathway subcollection fetched with msigdbr. KEGG data are not shipped with the package. Several `db` are scored one by one, never merged (`panoply_multi`).
* `split` now takes `"explore"` (default; 1a = change correlation inside the connecting pathways beyond random genes,
  as in the senescence case), `"rule"` (the benchmark coherence rule) or `"none"`; `TRUE`/`FALSE` still work.
* `plot_query()`: `"figure"` (all case panels a-e on one page, format of Figure 7 of the paper) and `"list"`
  (format of Figures 3c/3d); every panel drawn at journal text sizes. `panoply_figures()` writes both as PDF and PNG.
* `annotation` accepts LINCS pert_info or `signatureSearch::lincs_pert_info2` as they are: ID, name, MOA and target columns
  are found by name, and library columns are matched by full ID, the part before "__", or the BRD compound ID. The result
  gains a `target` column.
* No data are shipped with the package (KEGG copyright; MSigDB and LINCS terms): pathways are downloaded at run time,
  compound information comes from the user.
* `get_pathways()`, `panoply_toy()` (simulated data, generated by the function) and `inst/examples/toy_example.R`.
* `signature = "rankprod"` no longer needs MetaDE (archived on CRAN): the single-study rank product of MetaDE 1.0.5
  is built in (same algorithm; permutation draws differ, so FDR values can differ slightly from the paper's runs).
* `coh_cor()` gains `tail` (upper tail for `direction = "similar"`); `map_pathways()` records the mapping method.

# PAnoply 1.0.0

* First release: `panoply_query()` (two-group expression matrix to ranked compounds with tiers and connecting
  pathways), `plot_query()`, pathway mapping (`map_pathways()`, seven methods), WTCS (`prep_lib()`, `wtcs_query()`),
